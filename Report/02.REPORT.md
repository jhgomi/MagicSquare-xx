## 1. 개요

4×4 마방진(빈칸 2개, 1~16, 합 34) 학습자 페르소나를 대상으로 **Mom Test 준수/위반** 질문 10개를 정리했다. 카테고리별 ✅ 1문항 + ❌ 1문항(고친 버전 포함).

| Mom Test 단계 | 상태 |
|---------------|------|
| 질문 세트 작성 | ✅ 10문항 (✅ 5 / ❌ 5 + 고친 버전) |
| 카테고리 5종 | ✅ 각 2문항 |
| 01.REPORT 연계 | ✅ 대각선·검증·채점 후 발견 맥락 일치 |

## 2. 페르소나

4×4 격자, 빈칸 2개(`0`), 1~16, 행·열·대각선 합 34를 맞추는 **학습자** (손으로/코드로 다룸)

---

## 3. Mom Test 질문 10개

### 3.1 마지막으로 틀렸을 때

#### Q1 ✅
> 가장 최근에 4×4 마방진에서 빈칸 2개를 채웠는데 **틀렸다고 알게 된** 건 언제였나요? 그때 **어느 축(행/열/대각선)** 이 34가 아니었나요?

#### Q2 ❌
> 「SquareValidator로 10선을 자동 검증하면 마지막 실수를 줄일 수 있을 것 같나요?」

| 항목 | 내용 |
|------|------|
| **위반 이유** | 미래 가정 + 솔루션 이름·기능 선제시 → “좋다”는 답 유도 |
| **✅ 고친 버전** | 가장 최근에 “다 맞췄다”고 생각했다가 틀린 적이 있나요? 그때 **몇 번째 줄(행·열·대각)** 을 확인하지 않았나요? |

---

### 3.2 검증/확인 비용

#### Q3 ✅
> 마지막으로 10선(행 4·열 4·대각선 2) 합이 34인지 확인할 때, **처음부터 끝까지 몇 분** 걸렸나요? **어떤 순서**로 확인했나요?

#### Q4 ❌
> 「10선을 한 번에 검증해 주는 기능이 있으면 확인 시간이 줄어들까요?」

| 항목 | 내용 |
|------|------|
| **위반 이유** | “~하면 ~할 것 같다” 가설 질문 + 원하는 기능 선제시 |
| **✅ 고친 버전** | 10선을 전부 확인하는 데 **가장 오래 걸린 축**은 무엇이었나요? 그 축만 확인하는 데 **몇 분** 썼나요? |

---

### 3.3 포기·중단 순간

#### Q5 ✅
> 4×4 빈칸 2개 과제를 하다 **중간에 멈춘** 가장 최근 경우가 언제였나요? 멈추기 **직전 5분** 동안 정확히 뭘 하고 있었나요?

#### Q6 ❌
> 「이 과제가 너무 어려우면 그만둘 의향이 있나요?」

| 항목 | 내용 |
|------|------|
| **위반 이유** | 의향·태도 질문 → 실제 멈춘 **과거 행동**이 나오지 않음 |
| **✅ 고친 버전** | 마지막으로 이 과제를 **끝내지 않고** 다른 걸 한 적이 있나요? 그때 **몇 분** 하다가, **무엇 때문에** 손을 뗐나요? |

---

### 3.4 같은 문제를 다시 풀 때

#### Q7 ✅
> **같은** 4×4 격자(빈칸 2개 위치 동일)를 **두 번째로** 풀었던 마지막 기억이 있나요? 첫 번째와 비교해 **뭘 다르게** 했나요?

#### Q8 ❌
> 「복습용으로 같은 문제를 다시 풀게 해 주면 학습에 도움이 될 것 같아요?」

| 항목 | 내용 |
|------|------|
| **위반 이유** | 본인 아이디어(복습 기능)에 대한 동의 요청 |
| **✅ 고친 버전** | 틀린 뒤 **같은 격자**를 다시 풀었나요? 두 번째 시도에서 **처음과 다른 확인 순서**를 썼나요? |

---

### 3.5 다른 사람에게 설명/공유할 때

#### Q9 ✅
> 마지막으로 누군가에게 4×4 마방진(빈칸 2개·합 34) 풀이를 **설명**했을 때, 상대가 **가장 먼저 헷갈려 한 것**은 무엇이었나요? 그때 당신은 **뭘 보여 줬**나요?

#### Q10 ❌
> 「친구한테 설명할 때 ECB 구조나 코드로 보여 주면 이해가 빨라질까요?」

| 항목 | 내용 |
|------|------|
| **위반 이유** | 설명 방식(솔루션·아키텍처) 선제시 + 실제 경험 대신 의견 질문 |
| **✅ 고친 버전** | 마지막으로 설명할 때 **대각선 2개** 중 어느 쪽을 빼먹고 말했나요? 상대가 **뭐라고** 반응했나요? |
