## 1. 개요

`Report/03.REPORT.md`의 **R-G-I-O**와 **성공 기준 3개**가 `validate_lines` 계약과 일치하는지 대조 리뷰를 수행했다. 계약 기준은 `.cursorrules`(Entity·Control)와 `src/validate_lines.py` 시그니처·테스트 스텁(`tests/test_validate_lines.py`)이다.

| 리뷰 항목 | 판정 |
|-----------|------|
| 10선 합 34 전수 검사 | ✅ 일치 |
| 부분 검증(대각선 누락) 통과 금지 | ✅ 일치 |
| fail 시 실패 축 식별 | ✅ 일치 (축 ID 표기만 상이) |
| pass = 10축 + 숫자 규칙 동시 만족 (F3) | ❌ R-G-I-O·성공 기준에 누락 |
| `incomplete` 상태 (0 잔존) | ❌ R-G-I-O Output에 없음 |
| API·축 ID 명명 | ⚠️ 어긋남 (`validate` vs `validate_lines`, `row2` vs `R2`) |

## 2. validate_lines 계약 (기준)

| 항목 | 내용 |
|------|------|
| **진입점** | `validate_lines(grid) -> dict` |
| **반환** | `{"status": "pass" \| "fail" \| "incomplete", "failed_lines": list[str]}` |
| **10선 ID** | `R1`~`R4`, `C1`~`C4`, `D1`(주대각), `D2`(부대각) |
| **incomplete** | `0`(빈칸) 존재 — 10선 판정 전 종료, `failed_lines == []` |
| **fail** | 완성 격자이나 10선 중 합 ≠ 34 **또는** 숫자 규칙 위반(중복·범위) |
| **pass** | `0` 없음, 1~16 중복 없음, 10선 모두 합 34 |
| **failed_lines** | fail 시 깨진 축 ID 목록; pass·incomplete 시 `[]` |

## 3. 빠지거나 어긋난 항목

| 구분 | validate_lines 계약 (기준) | R-G-I-O / 성공 기준 (03.REPORT) | 문제 |
|------|---------------------------|--------------------------------|------|
| **Goal** | pass = **10축 합 34** + **0 없음** + **1~16 중복 없음** 동시 만족 | 행·열·대각선 **합 34** 판정 + 실패 **축** 식별만 명시 | **숫자 규칙(F3)** 이 Goal에 없음 |
| **Output** | `pass` / `fail` / **`incomplete`** + fail 시 `failed_lines` | `pass` / `fail`만 — **`incomplete` 없음** | 빈칸(`0`) 격자 처리가 계약과 불일치 |
| **Output** | 축 ID: `R2`, `D1` 등 | 예: `row2`, `diag_main` | **축 명명 규칙** 불일치 |
| **Input** | 4×4·값 범위·중복 위반 시 검증 거부 | “중복·범위는 Rule로 제한”만 — **validate 동작** 미명시 | 무효 입력 시 **fail/incomplete 반환** 미기술 |
| **Command** | `validate_lines(grid)` | `validate(grid)` (§4.2) | **함수명** 불일치 |
| **성공 기준 1** | **10축 + 숫자 규칙** 동시 검사 | **10축** 합 34만 검사 | Rule §4.1 **동시 pass 조건** 누락 |
| **성공 기준 2** | 축 합 ≠ 34 **또는** F3 위반 시 fail | “임의 **축** 하나만 34가 아니어도 fail” | **0 잔존·중복(F3) fail** 미포함 |
| **성공 기준 3** | 모든 fail 유형에 재작업 가능 정보 (F4; F3 포함) | “**어느 축**이 틀렸는지”만 | F3 실패 **출력 형식** 미정의 |
| **§5 F3 연계** | Rule·`.cursorrules`에 F3 포함 | R-G-I-O·성공 기준에 F3 **미언급** | F1·F4만 반영, **F3 빠짐** |

## 4. 일치 항목 (요약)

- **Role** — 학습자·검증 누락·20분 손실 맥락: 계약 범위 밖, 불일치 없음.
- **10선 전수 검사** — 성공 기준 1·Mom Test 증거 1과 F1 정합.
- **부분 통과 금지** — 성공 기준 2·증거 2(대각선 누락)와 Test Loop Red 케이스 정합.
- **실패 축 식별** — 성공 기준 3·F4·`failed_lines` 의도 정합 (ID 표기만 상이).
- `validate_axis`·`report_failures` — 선택/보조 Command; 핵심 계약 누락으로 보지 않음.
